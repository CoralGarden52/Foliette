# 可编辑文字贴纸

## 使用方式

打开编辑页的「贴纸 → 文字贴纸」，当前展示 611 款标签、便签、云朵、心形和票根：保留旧款 34 个入口，新增 577 款。旧款「雾蓝花朵对话框」已下架，不影响旧作品继续打开。点击添加或拖入画布后可直接填写正文；再次点击正文继续编辑，拖动边缘或移动手柄则整体移动。

清单保持模板预设行数，画布与「元素样式」均不再提供「新增一行」，输入换行也不再增加清单行标。所有新旧模板统一保持整张原始比例，不再延长纸面。文字在安全区域内自动适配显示字号，编辑与导出均完整适配，不显示正文滚动条；样式面板的正文输入框随内容增高。大量正文会使字号变小，文字总长度沿用 10000 字符限制。旧作品原有正文与清单行数继续兼容；已被拉长的文字贴纸打开时自动恢复原比例，文字、位置、角度和宽度保留。

新增素材中 17 个没有纸面留白的微型点缀，保留原图，并在下方透明区域提供可编辑配文；深色纸张默认使用浅色文字。

原素材中的「今日」「备注」「待办」「计划」等标题属于装饰背景，正文可编辑。字体、字号、颜色、粗细滑动条、对齐、移动、旋转、缩放、复制、图层和删除复用原有文字功能；粗细也可在「元素样式」中从常规逐步调整到更粗，正文按当前字重及笔画厚度重新适配留白区域。文字贴纸隐藏旧的纯色贴纸底选择器，避免将设计底图误当作普通背景操作。

## 数据与素材

- 保留 `kind: text`，新增可选 `noteTemplate` 和 `noteRows`，不改变旧文字与普通图片贴纸的数据。正文仍使用 `text`，不是烘焙到图片中的像素。
- 原有模板注册表位于 `web/src/data/textStickers.json`，新增三组来源表合并输出 `web/src/data/textStickers-imported.json`；`textStickers.ts` 维护可见素材与兼容模板映射。
- `assets/text-stickers/` 共 1261 张透明 PNG：原有 107 张与新增 1154 张预览/正文底图。原 35 张延展窄条仅作为历史生成产物保留，渲染已不再使用。素材不混入普通图片贴纸扫描，避免重复入口。
- 完整背景只按原比例绘制一次，不再使用顶部/中段/底部拉伸。旧款花园云朵花枝、格纹胶带纸仍叠加独立原比例装饰层；动态引导线和行标不改变装饰。非清单原纸面与格线原样保留，新增清单仅适配正文及审核过的 `checkArea` 标记列。
- 后端保留原有 35 个模板标识兼容旧作品，并接受 `server/src/data/textStickers-imported.json` 的 577 个新增白名单标识。清单预设行数必须是 3–30 的整数且仅用于清单，不接受任意素材网址或 SVG。
- 保存、撤销、复制、自动保存与图片导出使用同一份文本数据。导出前结束编辑，输入提示不参与导出。

## 来源与重建

原始参考图保存在 `docs/sources/text-stickers-reference.png`，分辨率 1254×1254，SHA-256 为 `a933a978330235b4ef5300a398181fb71c4f53d319f9ba78a13c08c355d9069a`。

整理工具需要 Python、Pillow、NumPy，复用同目录的连通区域处理函数。原图不修改，按审核坐标裁切为透明 PNG；仅适配固定印刷引导线和复选框区域，未 AI 重绘或放大素材。

```powershell
python scripts/prepare_text_stickers.py `
  docs/sources/text-stickers-reference.png `
  .playwright-mcp/text-sticker-review-assets `
  .playwright-mcp/text-sticker-review-registry.json
```

默认拒绝覆盖同名成品；`--replace` 只用于重新生成这一批已确认的文字贴纸。生产环境和 Docker 直接使用成品，不需要 Python。

新增批次的来源与重建方式见 [批量文字贴纸导入](text-sticker-library-import.md)。
