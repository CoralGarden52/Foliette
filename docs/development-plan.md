## 目标与设计

在现有 React / Vite + Express / SQLite 项目内完成可部署的个人手帐照片墙。首次访问进入邮箱密码登录；注册支持用户名、邮箱、密码、确认密码及内置头像。每位用户只能访问自己的照片墙与原图。

视觉调整为象牙白、橄榄绿与暖灰的编辑式手帐：真实摄影、克制的衬线标题、轻边框与柔和纸影；接入用户 assets/canvas 中 22 款纸张，以轻量缩略图选取、原图呈现和导出。桌面编辑器使用工具栏、画布和样式检查器，平板与手机使用底部工具和抽屉，并保留充分的画布区域及触屏操作空间。

重做 14 种布局并补充随机排布，保留 12 种相框、441 张素材及 SVG 图钉装饰。每面墙最多 20 张照片，支持自由拖拽、缩放、旋转、可编辑文字贴纸、自定义比例和 PNG/JPG 下载。自动保存必须避免并发覆盖，并支持保存失败重试与返回前保存；撤销不能破坏照片原文件。

补充交互：邮票四边齿孔相框与所有相框一键应用全部照片；排版只更新几何信息不覆盖相框。角标等比缩放，双指在同一张照片上缩放该照片、其他区域双指缩放视图。选中画布贴纸后点击素材直接置换；拖入始终新增，取消选中后点击也新增。随机排布每次改变行列、长宽、尺寸、位置、照片顺序与 ±19° 角度；先按旋转后包围盒计算单格安全尺寸，保证随机照片不重叠，结果保存为坐标，重开不会变动。

本轮完成本地开发与 Docker 部署准备。真正上线需要用户的服务器和域名。
