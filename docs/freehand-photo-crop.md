# 相片自由裁剪

选中照片后，桌面在「元素样式」点击「自由裁剪相片」，手机也可直接点击底部「裁剪」。在弹窗里，用鼠标按住拖动或单指沿想保留的区域圈选，松开后自动连接起点和终点。圈外以棋盘格显示透明区域；可重新绘制，确认后返回照片墙。

第一版保留一个闭合区域。点击或画线而没有圈出有效面积时不能确认；双指或系统中断会取消当前未完成的轨迹。圈选时相片固定，照片墙的移动和缩放不会干扰描边。

裁剪只保存轮廓，原图保持不变。照片的位置、尺寸和角度保留，仍能移动、缩放、旋转、复制和调整图层；「重新裁剪相片」始终打开原图供重新圈选。「恢复原图」移除轮廓并重新显示原有相框。取消弹窗或未确认的重绘不会改变已有作品，确认和恢复均支持撤销/重做。

## 实现与保存

- `PhotoItem.cropPath` 是相片原始内容中归一化的 `{ x, y }` 坐标数组，坐标范围为 0–1，与画布缩放及相片旋转无关。原图宽高比由 `aspectRatio` 保留。
- 鼠标和触摸通过 Pointer Events 共用输入；宽图或竖图的留白在坐标换算时排除。轨迹经过简化，保存 3–1024 个点及非零有效面积；前后端均限制坐标及路径范围。
- 照片墙及导出共同使用 SVG 图片和闭合裁剪蒙版。裁剪时相框隐藏，原 `frame` 和 `frameTone` 属性保留，恢复原图时重新显示。
- 旧作品无需迁移，没有 `cropPath` 的照片沿用原有显示方式。复制及历史快照携带同一份轮廓数据，编辑副本时通过替换数组独立修改。

## 验证

运行 `npm test` 检查坐标换算、路径闭合及简化、旧照片兼容，以及服务端对非法坐标、过多轨迹点和退化区域的拒绝。运行 `npm run build` 检查 TypeScript 并生成当前网站产物。

2026-10-19 回归：6 项自动测试、TypeScript 及生产构建通过。实际浏览器验证桌面圈选、预览、取消重绘、恢复原图及相框、撤销/重做、保存刷新；390px 手机原生触摸圈选、多指取消、系统触摸中断及保存重开通过，无页面横向溢出。复制后的两个蒙版标识独立，恢复副本不改变原照片轮廓。实际导出 PNG 解码为 1000×1000，像素检查确认圈外为画布背景、圈内保留照片，未包含预览轮廓线；非法裁剪路径的实际保存请求返回 400。
