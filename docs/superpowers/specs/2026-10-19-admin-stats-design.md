# Foliette 轻量统计后台

用户已确认：沿用 Express、SQLite 和 React，在 `/admin/stats` 展示七项指标及30天趋势，普通界面没有入口。此文记录已授权方案和实现口径，直接在当前会话执行。

- 权限：环境变量 `ADMIN_USER_IDS` 指定已存在账号的不可变 ID，默认无人拥有权限；不使用注册顺序、邮箱自动认领或客户端角色。HTML 路径和所有统计读取接口均在服务器校验；前端也在数据返回前不展示面板。未登录跳转现有登录页，完成后回到统计页；普通账号返回403。
- 指标：北京时间今日 PV、匿名浏览器去重 UV、当前累计账号数、今日新增账号、今日去重活跃账号、当前作品数、累计图片导出。趋势包括每天 PV、UV、新增、活跃、现存作品的创建数及导出。注册和作品从现有毫秒时间戳回溯；删除作品不保留历史创建事件，界面说明该口径。
- 采集：前端成功展示登录、注册、作品列表和编辑页面后发送浏览事件；同一页面的 React StrictMode 重放不重复计数。导出成功生成且触发下载后发事件，不统计预览和失败。服务器要求导出事件来自登录用户且拥有目标作品。已指定管理员不计入流量、活跃或导出。
- 去重和隐私：服务器 HttpOnly、SameSite=Lax 匿名随机 Cookie；数据库只保存每日 HMAC 标识，不保存 IP、邮箱、照片或具体页面地址。跨设备会被算作不同访客，清理 Cookie 会导致重复，禁止 Cookie 时只能近似。事件 ID 幂等；每天去重明细保留35天、汇总保留。采集失败不影响使用。
- 活跃：当天有成功作品接口访问或登录/注册、认证浏览事件的普通账号；页面长时间打开时，每分钟在可见状态上报一次活动心跳，不增加 PV。
- 安全：采集只接受规定类型和页面，拒绝跨站请求，限流；后台响应禁止缓存。公开采集是近似运营数据，无法保证阻止伪造流量。
- UI：沿用奶油纸张视觉，七张指标卡，可切换指标的30天折线图、每日明细、刷新、返回作品和退出登录；桌面和手机可用，错误可重试。
- 运维：Docker 透传管理员 ID；提供通过已注册邮箱查询 ID 的本地命令，不替用户指定管理员；说明配置、重启、采集起点和时间口径。

验证使用临时目录数据库，覆盖权限、提权尝试、去重、导出归属、时区、历史回溯、无事件日期、清理与重启持久性，以及桌面/手机页面。
