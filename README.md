# Foliette · 把日子，贴成喜欢的样子

奶油纸张、和纸胶带、拍立得和实物贴纸组成的个人照片墙。前端 React + TypeScript + Vite，后端 Express + SQLite；头像和贴纸直接使用仓库内的素材，字体随前端打包，不依赖外部 CDN。

## 已有功能

- 邮箱/密码登录；用户名、邮箱、密码、确认密码注册；16 个内置头像可选择和更换。
- 每人独立的照片墙列表，新建、重开编辑、删除、退出登录。作品和原图接口校验用户身份。
- 每面墙最多 20 张照片，支持一次选择 20 张、手机相册和拍照。大图在浏览器内按最长边 2400px 缩小，触屏设备使用 1600px 降低内存压力，单文件上限默认 12 MB。
- 16 种排版（含随机排布、满版拼贴）、12 种相框；按照片数量自动适配行列与照片大小，尽量铺满画布，末行也会均衡分配。照片、文字、贴纸自由拖动、缩放、旋转、调整图层、复制和删除；对齐参考线与撤销/重做。
- 全部 16 种排版按每张原图宽高比适配槽位，照片与侧栏缩略图均完整显示，不裁切填充。相框保留，异形装饰与照片分层；为完整呈现画面，部分相框保留适量留白。旧作品自动读取原图比例；极宽照片的相框内边距分别按高度和宽度计算，避免画面被挤没。
- 随机排布仍会改变行列、照片顺序、位置和 ±19° 角度，按旋转后的占位避免重叠；重复点击「随机排布」卡片即可重新随机，不再显示「再随机一次」等重复排布按钮。编辑器清理常驻操作说明，保留控件标签、悬停提示、容量/保存状态和错误反馈。
- 邮票相框具备四边齿孔；选择相框后可「应用到所有照片」，不改变位置或大小，切换排版保留相框。照片角标支持鼠标/触屏等比缩放，双指在同一照片上开合也能缩放照片。
- 相片支持「自由裁剪」：选中相片后，在元素样式中打开，手机也可直接点底部「裁剪」。用鼠标或单指圈出保留区域，松开自动闭合，预览后确认或重新绘制；圈外透明，原图保留。支持重新裁剪、恢复原图、撤销/重做、保存重开、复制及 PNG/JPG 导出。裁剪时隐藏相框，恢复原图后原相框重新显示，详见 `docs/freehand-photo-crop.md`。
- 相框统一为低饱和手帐风，并提供真实效果预览卡片。和纸胶带/胶带角可选鼠尾草绿、燕麦米、雾蓝，搭配细格纹、织纸和柔和条纹；胶片可选暖炭黑、复古棕、深橄榄绿，配奶油齿孔和细线。其他相框采用暖白纸感、细边和轻阴影；「应用到所有照片」同步相框及配色，支持撤销、保存、手机编辑和导出，照片始终完整显示。
- 新墙从空白纸张开始，不再提供固定装饰搭配；已有作品的贴纸原样保留。选中画布贴纸后，直接点素材即可替换并保留位置、大小和角度。点「添加新贴纸」取消选中，或直接拖入新素材；441 张素材与 SVG 图钉、钉子、胶带等装饰可自由使用。
- 空白文字与快捷短语可以直接拖入画布指定位置，手机使用右侧六点手柄；也可点击添加。文字可单击/轻点画布直接编辑，新文字自动进入输入；输入状态下仍可拖动文字，选中后另有独立移动手柄，手机触控同样支持。保留样式面板输入作为另一种入口。10 种字体选项包含 5 款本地开源中文手写字体，提供 WOFF2 文件与许可证，不依赖外部字体服务。字体、颜色、字号、间距、对齐和贴纸底可编辑；图层工具可选中被遮住的元素。
- 「文字」面板新增 30 款符号模板，按星月心情、花草日常、旅行片段、纪念标签、装饰分隔五类切换，保留原有 7 条快捷短语。支持带符号短句、多行题字和纯符号分隔线；添加后仍是可编辑文字，不是图片，点击或拖入均可使用。选中文字后，可在「文字」或「元素样式」中拖动「文字粗细」滑动条，从常规逐步调到更粗，适用于普通文字、颜文字和文字贴纸。固定字重的手写字体也支持逐级加厚；粗细随作品保存并用于导出，调整后自动适配文字高度，支持撤销/重做。
- 「贴纸 → 文字贴纸」提供 611 款便签、标签与造型纸张，包含本次从 15 张合图去重整理的 577 款新素材。点击或拖入后直接输入正文，支持整体移动、等比缩放、旋转、撤销、保存及导出。所有文字贴纸保持原始比例，正文自动适配留白区域；清单固定预设行数，取消新增行数按钮及正文滚动条，编辑时同样完整适配。易变形的旧款雾蓝花朵对话框已下架，旧作品仍兼容，详见 `docs/text-stickers.md`。
- 接入 `assets/canvas/` 的 28 款纸张（原有 22 款 + 6 款 AI 纸张），另有纯白画布和 8 款内置纹理画布，共 37 种选择。奶油素纸、方格纸、点阵纸、横线纸、牛皮纸、小格子、碎花、斜条纹均以预览卡片直接选择，使用固定配色和疏密，不再显示纹理、纹理颜色及疏密控件；旧作品已有设置保留。「茶灰宣纸」与此前指定的 10 款纸张优先展示。名称和预览按文件名映射，不因增加素材而错位；AI 生成提示词见 `docs/generated-canvases.md`。支持预设/自定义比例、串行自动保存、失败重试及返回作品列表前保存。
- 鼠标可从素材面板直接拖贴纸到画布；触屏按住素材右下角六点手柄拖入，也可点按添加。放置后继续移动、旋转、缩放或替换。原「装饰」分类的 16 款内置素材合并到「小元素」，小元素共 187 款，不影响已有作品。
- 从用户提供的 10 张合图中整理出 595 张独立透明 PNG，新增花园植物（184）、甜点茶歇（51）、旅行拾光（60）、心意装饰（300）四类。直接保留原始裁剪分辨率，不重绘或放大，舍弃无法完整切分与过小的素材；旧分类和作品保持不变。来源、审核规则和整理命令见 `docs/sticker-sheets.md`。
- 编辑页新增独立「手账工具」：纯色、条纹、格纹、波点、花卉胶带可拖拉铺贴，支持移动、旋转、缩放、透明度和图层调整。胶带大小直接在画布上拖动手柄调整，手账面板不再重复显示长宽数值框；未选中时仍可设置新胶带的铺贴宽度。取消普通剪刀，仅保留花边剪刀，提供波浪、锯齿、邮票、撕纸边及大小设置，可恢复完整胶带，不裁剪照片或贴纸。
- 钢笔、马克笔、荧光笔支持预设/自定义颜色与粗细；新增彩虹笔，同一笔沿书写路径连续变色，也可调整粗细。橡皮擦局部擦除笔迹并露出真实底层，不影响照片、文字、贴纸和胶带。笔迹完全擦净后同时从画布和图层移除，部分擦除仍保留；撤销/重做同步恢复或移除笔迹及图层，打开旧作品自动清理已擦空的历史笔迹并保存。笔迹与擦除一起移动、缩放或旋转，复制后独立编辑；每笔、每次裁剪/擦除及连续胶带参数调整可一次撤销。手机工具抽屉配合画布浮动工具条，双指缩放会取消未完成的笔画；新元素均可保存、重开并导出 PNG/JPG。
- 选中画布上的贴纸后按 `Delete` 或 `Backspace` 删除，`Ctrl/⌘ + Z` 撤销。点击、旋转、缩放画布元素时键盘焦点回到画布；输入文字、调整输入框、中文输入法组词或操作弹窗时不会误删元素。
- PNG/JPG 下载及当前画布预览。先选择标准/高清/超高清和 PNG/JPG，再点击下载才生成文件；选择清晰度本身不会下载。导出嵌入当前所用的本地字体，不包含编辑画布的外阴影和圆角；极端比例自动限制到最长边 8192px、总像素 1600 万以内，减少手机内存压力。
- 作品首页采用克制的排印、浅色边框与收藏统计；新建照片墙始终是第一张卡片，顶部不再重复提供新建按钮。
- 编辑器顶部以作品名与铅笔入口替代整行输入框，点击后通过命名弹窗修改；确认后自动保存，支持中文输入法与撤销。登录页移除指定的两处宣传文案。
- 桌面三栏编辑器，手机/平板底部工具抽屉，手指拖动与双指缩放；支持减少动态效果的系统偏好。
- 底部缩放百分比可直接点击输入，支持小数、回车/失焦应用、Esc 取消及非法输入恢复；桌面和手机统一表示实际画布比例，范围 0.1%–300%。手动比例不受窗口或软键盘尺寸改变影响，使用「适应画布」图标回到自动适配；视图缩放不改变照片尺寸或导出分辨率。拍立得保留经典白边，不再编辑或渲染照片说明文字。

## 隐藏统计后台

访问 `https://你的域名/admin/stats`，普通页面没有管理入口。页面路径和 `/api/admin/stats` 接口均由服务器验证管理员权限：未登录访问页面会进入现有登录页，登录后返回后台；普通账号不能查看数据。默认管理员列表为空，不会自动将首个注册账号设为管理员。

先通过网站注册自己的账号，再在服务器上查出对应的用户 ID：

```sh
npm run admin:user -- your-email@example.com
```

命令只读数据库，输出 `ADMIN_USER_IDS=u_...`。将它设置为服务器环境变量，再重启服务；多个管理员 ID 用英文逗号分隔。普通注册或个人资料编辑不能修改管理员权限。撤销 ID 后重启即可撤销访问，即使原会话仍有效。

Docker 部署时，在已有容器内查询实际数据卷中的账号：

```sh
docker compose exec foliette node src/admin-user.js your-email@example.com
```

把输出的 `ADMIN_USER_IDS=...` 写入宿主机 `.env`，然后执行 `docker compose up -d --build`。本地 `npm start` 不会自动加载 `.env`，需自行设置环境变量；查询命令和网站服务应使用相同的 `DATA_DIR`。Docker 镜像也包含此查询脚本。

后台展示今日浏览量、今日访客、累计注册、今日新增、今日活跃、当前作品总数和累计图片导出，提供含今天的30天趋势及每日明细。所有日期以北京时间（UTC+8）划分，与服务器时区无关。

- PV 按登录、注册、作品列表、编辑页的前端访问事件计数；页面内点击不会自动增加 PV。
- UV 按匿名浏览器 Cookie 每日去重，跨设备、清理 Cookie 或禁用 Cookie 可能造成偏差；数据库仅保存每日 HMAC 标识，不记录 IP、具体页面地址或照片内容。
- 活跃用户是当天成功登录、注册、访问作品接口、浏览页面或发送可见页面心跳的去重账号。指定管理员登录后的 PV、UV、活跃和导出不计入运营流量；注册总数、作品总数仍包含管理员。
- 导出事件在图片生成并触发下载后记录，不包括预览、生成失败，也不能确认浏览器是否最终保存文件。采集失败不阻塞编辑和下载。
- 注册和现存作品的创建时间可回溯；已删除作品不计入作品历史。访问、活跃和导出仅从启用此功能后积累，界面显示采集起点，之前日期显示“—”。
- 统计数据存放在现有 SQLite 数据库中，沿用原备份和数据卷。去重明细自动保留约35天，日汇总和累计导出保留；公开事件采集仅用于近似运营观察，可能受脚本拦截、机器人和伪造请求影响。

## 本地开发

照片已支持本地存储与阿里云私有 OSS。`foliette-photos-prod`（深圳）的 RAM 授权、密钥配置、连接测试、腾讯云部署和可选迁移步骤见 [OSS 接入说明](docs/oss.md)。默认仍为 local；填好本机 `.env.oss` 后先运行 `npm run oss:check`，通过后再用 `npm run start:oss` 启动。不要把真实密钥发到聊天或提交仓库。

需要 Node.js 22.12 或更新版本，推荐 Node.js 24 LTS。

```sh
npm run setup
npm run dev
```

打开 http://localhost:5173 。API 默认 http://localhost:8787 。首次访问进入登录页，自行注册即可使用。项目没有预置管理员或公开演示密码。

手机与电脑在同一网络时，打开开发服务器打印的 Network 地址；需允许系统防火墙访问 5173 端口。移动端选中文字后点击「编辑文字」，选中图片/贴纸后点击「样式」。拖动空白处移动画布，双指、加减按钮或输入缩放百分比调整视图，点击「适应画布」图标恢复自动适配。

```sh
npm run check
npm test
npm run build
npm start
```

构建后的前端由后端直接提供，打开 http://localhost:8787 。本地默认数据位于 `server/data/`，默认前端产物为 `web/dist/`。`npm start` 使用当前进程环境；`.env` 由 Docker Compose 自动读取，本地开发不自动加载生产配置。

## Docker 部署

1. 复制 `.env.example` 为 `.env`。
2. 使用下面的命令生成随机密钥，填入 `.env` 的 `JWT_SECRET`。至少 32 个字符；默认开发密钥和示例占位内容不能用于生产。

```sh
node -e "console.log(require('node:crypto').randomBytes(48).toString('hex'))"
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 foliette
```

默认端口为 8080，打开 http://服务器地址:8080 。`GET /api/health` 是健康检查。镜像分阶段构建，使用非 root 用户、只读根文件系统，SQLite 和上传文件写入 `foliette-data` 命名卷；重启和重建镜像保留数据。仅在一个服务实例中使用该 SQLite 数据卷。

需要域名与 HTTPS 时，可将 Caddy 放在宿主机上，并转发到容器发布的 8080 端口：

```caddyfile
photos.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

启用 HTTPS 后设置 `COOKIE_SECURE=1`，反向代理只有一跳时设置 `TRUST_PROXY=1`，然后 `docker compose up -d`。可将 Compose 的端口绑定改为 `127.0.0.1:8080:8080`，只允许反向代理访问。使用 Nginx 时需将请求大小上限设置为至少 256 MB，容纳最多 20 张原始照片的一次上传。

| 变量 | 默认/用途 |
| --- | --- |
| `PORT` | 对外发布端口，默认 8080 |
| `JWT_SECRET` | 生产环境必填的随机登录签名密钥 |
| `JWT_EXPIRES_IN` | 登录有效期，默认 `30d` |
| `COOKIE_SECURE` | HTTPS 部署设置为 `1`，本地 HTTP 为 `0` |
| `TRUST_PROXY` | 默认 `0`；一层可信反向代理时为 `1` |
| `MAX_PHOTOS_PER_WALL` | 默认 20，不能超过 20 |
| `MAX_UPLOAD_BYTES` | 单图上传上限，默认 12582912 字节 |

容器内固定使用 `/app/data`、`/app/assets` 和 `/app/public`。如需更新内置素材，可额外挂载 `./assets:/app/assets:ro`。

备份时先停止服务，再完整备份命名卷，随后启动服务；需要同时保留 `foliette.db`、可能存在的 WAL 文件和 `uploads/`。恢复时保持相同目录结构。`docker compose down` 保留数据，带 `-v` 会删除数据卷。

## 编辑与浏览器说明

- 删除画布元素不会立即删除原图，因此复制、删除后撤销和重做仍然有效。删除整面照片墙时统一清理它的上传文件。
- 默认支持 JPG、PNG、WebP、GIF、AVIF。HEIC/HEIF 会尝试使用浏览器解码并转成 JPG；浏览器不支持时会提示先在相册转为 JPG/PNG。
- 图片从浏览器下载目录获取；部分手机浏览器需通过下载列表再保存到相册。
- 浏览器关闭或刷新前若存在未保存修改会提示；断网时请保留页面，恢复连接后点击保存。
- 当前不包含邮件验证、找回密码或多人协作。本轮提供 Docker 上线准备，实际部署需要服务器、域名和 HTTPS 配置。
